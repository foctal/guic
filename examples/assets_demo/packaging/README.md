# Packaging fixture artwork

The PNG and ICO are generated geometric fixture artwork under the repository's
Apache-2.0 license. They are intentionally separate from GUIC product branding.
The ICO contains the same 128-pixel PNG. See the
[CLI guide](../../../docs/cargo-guic.md#windows-executable-resources) for executable
icons and the [packaging guide](../../../docs/packaging.md) for native distribution.
