# guic-packager-utils

Shared package-format types and executable-path utilities for the
`guic-packager` crate family. Application code normally uses the packager,
updater, or resource resolver instead of depending on this crate directly.

The `serde`, `schema`, and `clap` features enable the corresponding integrations.
